# The Network Sales Site

The landing page and offer page for The Network, a trading community I ran. These pages fed an application pipeline: a visitor applied through an embedded Tally form, and the application flowed into a CRM for review.

## What's here

- `index.html`: the landing page
- `offer.html`: the offer page
- `server.js`: a small Express server for the two pages

## Run it

```bash
npm install
node server.js
```

Then open `http://localhost:3000`.

## About this repository

A clean public copy with fresh history. The Network is no longer operating, so this is an archive of the work. All rights reserved.
